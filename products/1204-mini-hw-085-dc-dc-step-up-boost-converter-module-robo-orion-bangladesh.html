The HW-085 (also known as the BS01) DC-DC Step Up (Boost) Converter is an incredibly compact and versatile power module designed for DIY electronics and hobbyist projects. This tiny board takes a low DC input voltage—from 2.5V up to 5V—and efficiently boosts it to a stable, higher output voltage. If you're looking for the best HW-085 boost converter price in Bangladesh, Robo Orion provides the most competitive pricing for this essential module.

What makes this module (HW-085 / BS01) unique is its easy hardware configurability. Instead of a bulky, fragile trim potentiometer, it uses fixed solder pads (labeled A and B) to select the output voltage. By default, it is set to output 12V, but with a quick touch of a soldering iron, you can configure it to output 5V, 8V, or 9V depending on your project's needs.

The board includes a power indicator LED that consumes approximately 1mA of current. For ultra-low power or battery-operated projects, you can disable this LED by breaking the small solder pad next to it, bringing the no-load quiescent current down to less than 1mA.

Please note: The input voltage must always be lower than your desired set output voltage. Output current capability depends entirely on the input-to-output voltage ratio.

Voltage Configuration Guide (A & B Pads)

On the front of the PCB, locate the pads labeled A and B. Modify the solder bridges to change the output voltage (0 = Open/Disconnected, 1 = Shorted/Connected). *Note: The default state out of the factory is 12V.*

  • 5V Output: A = 0, B = 0
  • 8V Output: A = 0, B = 1
  • 9V Output: A = 1, B = 0
  • 12V Output: A = 1, B = 1
